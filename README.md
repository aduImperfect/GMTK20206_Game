# GMTK2026_Game

Cards Legend (Scroll for Controls):
🗲 = Deck BG
🡢 = Move Forward
🡠 = Move Backward
↗ = Jump Forward
↑ = Jump Upward

Controls (Keyboard | Controller):
🡠,🡢 Keys | D-pad | Axis = Highlight
➖ | A | X | RT = Long Press Select

Godot Ver 4.7

Textures: Made on our own.
Emojis: Taken from: https://emojicombos.com/
